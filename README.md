# 💬 Chat

Простое веб-приложение чата для обмена сообщениями в реальном времени.

## 📖 Описание

Проект представляет собой клиентскую часть чата, реализованную на чистом JavaScript. Позволяет пользователям отправлять и получать сообщения через API.

## 🛠️ Технологический стек

- **Языки:** JavaScript (ES6+), HTML5, CSS3
- **Сборка:** Webpack 5 (common, dev, prod конфигурации)
- **CI/CD:** AppVeyor
- **Зависимости:** npm (package.json)

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/chat.git
   cd chat
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите в режиме разработки:**
   ```bash
   npm run dev
   ```

4. **Сборка для продакшена:**
   ```bash
   npm run build
   ```

## 💻 Примеры использования

**Открытие чата в браузере:**
```bash
# После запуска dev-сервера откройте:
http://localhost:8080
```

**Отправка сообщения (через консоль браузера):**
```javascript
// Пример отправки сообщения через API
const chat = new Chat();
chat.sendMessage('Привет, мир!');
```
